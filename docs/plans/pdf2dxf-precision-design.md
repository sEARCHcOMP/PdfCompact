## 2. 誤差の正体(モンテカルロ 各20万回。600dpi・1/100・10,000mm を測った時の誤差 mm)

| やり方 | ふつう(RMS) | 95%点 | 最悪 |
|---|---|---|---|
| 今: 3,640 の1か所で合わせる | 4.6 | 10.7 | 17.6 |
| 一番長い通し寸法(10,920)で合わせる | 2.6 | 4.8 | 9.9 |
| 縦横2か所(10,920+7,280) | 2.3 | 4.5 | 10.5 |
| 寸法文字30か所で自動(現実的な相関あり) | 2.3 | 4.5 | 7.5 |
| **標準縮尺ちょうどと確認できた時** | **1.7** | **3.4** | **6.0** |
| 床(測る線の両端の丸めだけ。どの方法でも消せない) | 1.7 | 3.4 | 6.0 |

- 誤差は2種類。(a) 縮尺の誤差 = 長さに比例。消せる。(b) 測る線の両端の丸め = 長さに無関係の「床」。1目盛りの実寸 g = 25.4×縮尺分母÷dpi mm(600dpi・1/100 で 4.2mm)に比例。1200dpi で半分、CAD直接出力なら 0.05mm 以下。
- 寸法を何十か所使っても √N では良くならない(同じ通り芯を共有するので丸めが相関する。改善は2〜3割)。**一番効くのは「標準縮尺ちょうど」を採用して縮尺の誤差をゼロにすること。**
- Microsoft Print to PDF は 600dpi 固定(1200 を要求しても無視。実測)。Jw_cad 由来PDFの最頻ケース。

## 3. 提案する設計

### 第1段(確実に効く・リスク小)
1. **標準縮尺の確認・採用(ルールR)**
   - u = 1目盛り ÷ 測った寸法の目盛り数(= q/d)。
   - u > 0.15% なら判定しない →「もっと長い寸法で確認してください」。
   - |測定分母÷標準分母 − 1| ≤ max(1.5u, 0.03%) なら標準値ちょうどを採用。外れたら測定値のまま使い「等倍ではなさそうです」と表示。
   - 短い寸法で通った時は、最長の通し寸法でもう一度確認して確定。
   - 保証: 等倍の取りこぼし 0%、0.5%以上の縮みの誤採用 0%(全条件)。10,920 で裏取りすれば 600dpi・1/100 の残留は 0.06% 未満(10m で最大 5.9mm)。許容を 2u・4u に緩めるのは不可(誤採用が出る)。
2. 手で合わせる時は「一番長い寸法で」に誘導。縦横2か所を足せるようにして平均する。縦と横で縮尺が食い違ったら(0.05%超)警告。
3. 表示: 「このPDFの1目盛り = 実寸 ○mm」を常時表示。測った長さごとに ±。吸着なしで合わせた時の注意は保存まで残す。
4. ③ 吸着: ルーペ+候補が複数ある時だけ拡大図で選び直し。
5. 取説に「PDFのもらい方」(CADデータが最善 / CAD直接出力 / 倍率100% / 1200dpi以上 / 文字はアウトライン化しない / ソフト別の設定)。

### 第2段(本物のCAD図面PDFで確かめてから)
- 寸法文字と寸法線を自動で突き合わせて縮尺を**提案**する(自動適用はしない。必ず利用者が1か所確認)。
- 試作2本: 標準ベンチ 86 件で OK 80 / 正しい辞退 6 / 誤答 0。6万本の線で 66〜170ms。
- 意地悪テスト 100 件では「自信ありげな誤答」が A=11・B=15。ガード5種で 3・4 まで減るがゼロではない。残る型: cm 単位の図面、建具記号の番号、表のマス、累進寸法、縦横で倍率の違うPDF、詳細図の同居。
- 採用するなら: A の照合(構造的なつながりを要求)+ B の標準縮尺の判定・縦横の一致確認・縮尺表記の読取り + ガード G1〜G13。
